# Sitemap protocol schemas (third-party)

`sitemap.xsd` and `siteindex.xsd` are unmodified copies of the Sitemaps.org protocol 0.9 schemas:

- https://www.sitemaps.org/schemas/sitemap/0.9/sitemap.xsd
- https://www.sitemaps.org/schemas/sitemap/0.9/siteindex.xsd

The protocol is published by its sponsors (Google, Inc., Yahoo, Inc. and Microsoft Corporation) under the Creative
Commons Attribution-ShareAlike 2.5 licence, https://creativecommons.org/licenses/by-sa/2.5/ (terms:
https://www.sitemaps.org/terms.html). The two files are test data for `SiteMapControllerSchemaTest` and are not part
of the built application. Do not edit them.

`sitemap-image.xsd` and `xhtml-link.xsd` are minimal stand-ins written for this project.
