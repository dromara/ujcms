  4. 提交成功后，请务必保存好信件编号和查询码，以便查询办理进度、答复结果并进行满意度评价。
  5. 经您同意公开的来信，答复后可能选登于本页面，选登时将对您的姓名作脱敏处理，不显示联系方式。
